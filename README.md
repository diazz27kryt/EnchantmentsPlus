# EnchantmentsPlus

Fabric mod for **Minecraft Java 1.21.11**.

## Planned enchantments
- **Шокированный** — mace strikes while falling summon lightning.
- **Шахтёр I–II** — mines a 3×3 or 5×5 area.
- **Верность IV** — helps locate a lost thrown trident.
- **Посейдон** — hold sneak after throwing a trident to pull yourself toward it.

The project is built automatically by GitHub Actions. Download the artifact named
`EnchantmentsPlus-Minecraft-1.21.11` from the latest successful workflow run.

## Build
Requires Java 21 and Gradle:
```sh
gradle build
```
